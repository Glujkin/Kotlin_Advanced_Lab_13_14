# Лабораторная работа №13-14
Коллекции, обобщения и функциональный стиль в Kotlin

## Описание
Данная лабораторная работа посвящена изучению продвинутых возможностей языка Kotlin, которые активно используются при разработке Android-приложений.

### Изученные концепции

#### 1. Обобщённые типы (Generics)
* Создание универсальных классов
* Работа с плейсхолдерами типов
* Применение в реальных задачах
* Примеры использования в коллекциях

#### 2. Коллекции Kotlin
* **Массивы** - фиксированный размер, быстрый доступ
* **Lists** - изменяемые упорядоченные коллекции
* **Sets** - неупорядоченные коллекции без дубликатов
* **Maps** - пары ключ-значение

#### 3. Функции высшего порядка
* **forEach()** - перебор элементов
* **map()** - преобразование элементов
* **filter()** - фильтрация по условию
* **groupBy()** - группировка элементов
* **fold()** - аккумуляция значений
* **sortedBy()** - сортировка

#### 4. Продвинутые возможности языка
* Extension-функции и свойства
* Интерфейсы и их реализация
* Scope-функции (let, apply, also, run)
* Singleton-объекты
* Data-классы
* Enum-классы
### Практические примеры
#### Работа с коллекциями
```kotlin
// Пример работы с List
val numbers = listOf(1, 2, 3, 4, 5)
val squared = numbers.map { it * it }
val even = numbers.filter { it % 2 == 0 }

// Пример работы с Map
val planets = mapOf(
    "Mercury" to 0,
    "Venus" to 0,
    "Earth" to 1
)

// Пример работы с Set
val uniqueNumbers = setOf(1, 2, 3, 2, 1)

// Пример использования filter и map
fun processNumbers(numbers: List<Int>): List<String> {
    return numbers
        .filter { it > 0 }
        .map { "Число: $it" }
}

// Пример использования fold
fun sumNumbers(numbers: List<Int>): Int {
    return numbers.fold(0) { sum, number -> sum + number }
}
```
